## 🎯 Purpose of This Portfolio

 This portfolio is fully designed and developed by me to demonstrate:

- Frontend engineering best practices

- Component-driven React architecture

- Clean UI/UX with smooth animations

- Real-world project ownership and decision-making

It is intentionally built to help recruiters and hiring managers quickly understand how I think, build, and solve problems.

## 🧠 What Makes This Portfolio Different

- Not a template

- No UI libraries for layout or modals

- Built from scratch using React + Tailwind CSS

- Designed with recruiter experience in mind

- Each project presented as a technical case study

## 🛠️ Tech Stack

<div align="center">

| React.js | Tailwind CSS | Framer Motion | Vite |
| React Hooks | Responsive Design | Micro-interactions | Git & GitHub |
| Component Architecture | Dark UI | Page Transitions | npm |

## ✨ Key Features

- Custom dark theme with consistent background flow

- Smooth Framer Motion animations (no slide-like sections)  

- Fully responsive (mobile, tablet, desktop)  

- Modular, scalable component architecture  

- Advanced project presentation:
  - Clickable project cards
  - Custom modal system (built from scratch)
  - Project deep-dive:
    - Full description
    - Features
    - Challenges
    - What I learned
    - Tech stack
    - GitHub & Live links
    - Image carousel (multiple screenshots)

- Fast build & performance using Vite
